# BGM 资源目录

请将以下 BGM 文件放到此目录：

| 文件名 | 用途 | 建议时长 | 循环 |
|--------|------|----------|------|
| `lobby.mp3` | 大厅/等待页面 | 2-3分钟 | ✅ 循环 |
| `game.mp3` | 游戏进行中 | 2-3分钟 | ✅ 循环 |
| `win.mp3` | 胜利结算 | 5-10秒 | ❌ 单次 |
| `lose.mp3` | 失败结算 | 5-10秒 | ❌ 单次 |

## 推荐免费资源

1. **Pixabay Music** - https://pixabay.com/music/
   - 搜索 `chinese traditional`, `mahjong`, `card game`
   
2. **Freesound** - https://freesound.org/
   - 搜索 `chinese ambient`, `casino`

3. **Mixkit** - https://mixkit.co/free-stock-music/
   - 搜索 `asian`, `game`

## 音量建议

- 大厅 BGM: 30% 音量
- 游戏 BGM: 20% 音量（不干扰思考）
- 胜利/失败: 50% 音量

## 格式要求

- 格式: MP3 (推荐) 或 OGG
- 采样率: 44100Hz
- 比特率: 128-192kbps (网页足够)
- 文件大小: 建议每个不超过 2MB
